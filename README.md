# Rio Tinto (rio-tinto)

Rio Tinto is a British-Australian multinational mining and metals corporation and one of the world's largest producers of iron ore, aluminum, copper, and diamonds. Rio Tinto does not publish a public developer API but operates supplier portals and the START traceability program.

**URL:** [https://www.riotinto.com/](https://www.riotinto.com/)

**GitHub:** [https://github.com/rio-tinto](https://github.com/rio-tinto)
